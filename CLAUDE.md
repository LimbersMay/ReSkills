# ReSkills

Marketplace de skills `limbersmay`. Las reglas generales del usuario están en `~/.claude/CLAUDE.md`.

## Skills genéricas

Este repo no depende de ningún producto, y las skills tampoco.

- **Los ejemplos son ficticios,** inventados para el caso, nunca de un producto real del usuario.
- **Las skills se pulen con el uso:** se usan en un producto real y se arregla lo que falla. Lo propio de
  ese producto no entra en la skill; si hace falta, va al `AGENTS.md` del producto.
